Capabilities

What it can do

A full-stack IoT system running on ESP32, delivering real-time sensor data to any browser

Radar Scanning

HC-SR04 on a servo sweeps 0–180°. Objects plotted live on a canvas radar with EMA smoothing and ping-pong extrapolation between updates.

HC-SR04ServoCanvas

LED Room Control

4 rooms independently, or all at once. Optimistic WebSocket UI gives <50ms visual response. ESP32 executes within 300ms via threaded command poll.

4 RoomsWebSocketThreaded

Protect Mode

Proximity-aware alarm: buzzer beep rate scales with how close an object is to the radar. Flame and gate events trigger instant alerts.

BuzzerProximityEdge Detect

Live Analytics

MongoDB Atlas logs LED sessions (on-time, energy in Wh), flame events with duration, and gate open/close history. Stats refresh every 5 seconds.

MongoDBSessionsEnergy
